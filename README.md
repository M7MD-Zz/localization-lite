## ✨ الميزات

- 🇸🇦 **عربي بالكامل** — بلا نظام لغات
- 🎨 **5 ثيمات**: داكن / فاتح / ريترو / أكاديمي / سايبر (اختيار محفوظ)
- 🔍 **بحث فوري** يغطي كل البطاقات + اقتراحات سريعة (آفاق، رحلة، هشام) + مشاركة نتائج البحث عبر `?q=`
- 📡 **أعداد أعضاء ديسكورد حية** تُجلب من API ديسكورد (مع أرقام ثابتة كاحتياط)
- 🧪 **مدقق ذاتي مدمج**: افتح `index.html?check` لفحص البنية والروابط والعدّادات (7 فحوصات)
- 📱 **متجاوب بالكامل** (جوال/تابلت/سطح مكتب)
- 🏛️ **توثيق صارم**: كل معلومة بمصدر متحقق منه — راجع `SOURCES.md`

## 📁 بنية المشروع

```
شيء/
├── index.html            ← الموقع كاملاً (CSS وJS مضمّنان داخله)
├── SOURCES.md            ← أرشيف المصادر والتحقق من كل بطاقة
├── validate_site_v2.py   ← فحص البنية: py validate_site_v2.py index.html
├── check_links.py        ← فحص الروابط: py check_links.py index.html
├── og-image.svg/.png     ← صورة المشاركات (يُولّد الـ PNG عبر make-og-image.html)
├── make-og-image.html    ← يحوّل og-image.svg إلى og-image.png في المتصفح
├── robots.txt            ← إرشادات محركات البحث
└── sitemap.xml           ← خريطة الموقع للأقسام الحالية
```

## 🔒 قواعد التوثيق (لا تُنتهك)

1. ممنوع اختلاق أي اسم/رابط/رقم/تاريخ — كل معلومة بمصدر متحقق.
2. كل بطاقة جديدة تحتاج رابطاً واحداً شغّالاً على الأقل.
3. لا محتوى قرصنة — تعريب/ترجمة فقط.
4. عند الشك: لا تُنشر، تُسجَّل في `SOURCES.md` بانتظار مراجعة يدوية.
