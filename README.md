# موسوعة تعريب الألعاب العربية — النسخة المبسطة 🎮

نسخة مبسطة من «موسوعة تعريب الألعاب العربية» — تحتوي على:
- **الصفحة الرئيسية** (هيرو + زرّي استكشاف + روابط التواصل)
- **سيرفرات الديسكورد** (32 سيرفراً)
- **مواقع التعريب** (29 موقعاً — تشمل مواقع/مدونات المعرّبين والأرشيف مثل خارقو العادة، بيكسل عرب، تعريبات منسيات)

النسخة الكاملة (الألعاب، المعرّبون، الأدوات، الأرشيف، الخط الزمني، القصص) قريباً.

## الملفات
| الملف | الوصف |
|---|---|
| `index.html` | الموقع كاملاً في ملف واحد (الأنماط والجافاسكريبت مضمّنة داخله — لا ملفات خارجية) |

## الرفع مجاناً

### الخيار 1: GitHub Pages (الأسهل والأشهر)
1. أنشئ مستودعاً جديداً على GitHub (مثلاً `lite`) — عام أو خاص.
2. ارفع ملف `index.html` في جذر المستودع.
3. من إعدادات المستودع: **Settings ← Pages** ← اختر `Deploy from a branch` ← الفرع `main` ← المجلد `/ (root)` ← Save.
4. خلال دقيقة يصبح موقعك متاحاً على: `https://<اسمك>.github.io/<اسم-المستودع>/`

### الخيار 2: Netlify Drop (أسرع — بدون حساب GitHub)
1. ادخل على https://app.netlify.com/drop
2. اسحب مجلد `sg22` وأفلته في الصفحة.
3. يتم رفع الموقع فوراً ويُعطيك رابطاً مثل `https://xxx.netlify.app`.

### الخيار 3: Vercel
1. ادخل على https://vercel.com/new
2. اختر مجلد المشروع واسحبه، وسيُنشر مباشرة.

## ملاحظات
- الموقع يدعم **الوضع الداكن/الفاتح** (زر القمر/الشمس أعلى اليسار) و**RTL** بالكامل.
- كل بطاقة رابطها الأصلي (ديسكورد / الموقع) — أي رابط ميت أبلغني لأصلحه أو أستبدله بأرشيف Wayback.
- عند النشر الفعلي: حدّث وسم `og:url` في `<head>` برابطك الحقيقي إن أردت مشاركة أفضل.
